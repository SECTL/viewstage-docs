文档扫描

ospneam

文档扫描

功能概述

ViewStage 提供 AI 驱动的文档扫描增强功能，支持边缘检测、文本检测、透视矫正和图像增强。

架构

文档扫描功能分为前端和后端两部分：

  • 前端: src/doc-scan/ — 文档扫描界面和交互逻辑
  • 后端: Rust 图像处理管道

AI 模型

ViewStage 支持三种 AI 模型：

1. DexiNed 边界检测模型

  • 文件: dexined_mbv4.onnx
  • 功能: 边缘检测 → 文档边界识别 → 透视矫正
  • 优先级: 最高（优先使用）
  • 硬件加速: DirectML（GPU）

2. DBNet 文本检测模型

  • 文件: text_detection_db_TD500_resnet18.onnx
  • 功能: 文本区域检测 → 自动裁剪
  • 大小: 约 54MB
  • 下载: 内置自动下载（ModelScope 源）

3. UVDoc 文档矫正模型

  • 文件: uvdoc.onnx
  • 功能: 弯曲/折叠文档图像矫正
  • 大小: 约 30MB

处理管道

输入图像
  → DexiNed 边缘检测（如模型可用）
    → 成功 → 透视变换矫正
    → 失败/不可用
  → DBNet 文本检测（如模型可用）
    → 检测到文本区域 → 裁剪
    → 未检测到 → 保持原图
  → 图像增强（锐化、二值化等）
  → 输出结果

设置选项

基本设置

  • 显示文档扫描按钮
  • 扫描质量（标准/高质量/超高质量）
  • 扫描模式（自动/手动）
  • 增强模式（自动/文本增强/照片增强/无）

模型管理

  • 导入/删除 DexiNed 模型
  • 下载/删除 DBNet 模型
  • 下载/删除 UVDoc 模型
  • 模型状态检查
  • 下载进度显示
