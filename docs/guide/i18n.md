# 国际化

## 支持的语言

| 语言 | 代码 | 文件 |
|------|------|------|
| 简体中文 | `zh-CN` | `locales/zh-CN.json` |
| 繁體中文 | `zh-TW` | `locales/zh-TW.json` |
| English | `en-US` | `locales/en-US.json` |

## 切换语言

1. 点击设置按钮打开设置面板
2. 在"应用设置"页面选择语言
3. 重启应用生效

## 语言文件结构

语言文件位于 `src/locales/` 目录，按功能模块组织：

```json
{
  "common": { /* 通用词汇 */ },
  "loading": { /* 加载提示 */ },
  "sidebar": { /* 侧边栏 */ },
  "toolbar": { /* 工具栏 */ },
  "docScan": { /* 文档扫描 */ },
  "settings": { /* 设置面板 */ },
  "camera": { /* 摄像头 */ },
  "errors": { /* 错误提示 */ },
  "oobe": { /* 首次引导 */ },
  "about": { /* 关于页面 */ },
  "rotation": { /* 旋转 */ }
}
```

## 国际化系统实现

`src/i18n.js` 实现了轻量级国际化引擎：

```javascript
// 初始化
await i18n.init_start();

// 翻译（支持参数插值）
i18n.format_translate('loading.processingPage', { current: 1, total: 10 });

// 切换语言
await i18n.update_locale('en-US');

// 自动渲染页面文本
i18n.render_page_texts();
```

### 属性绑定

| 属性 | 用途 |
|------|------|
| `data-i18n` | 设置文本内容 |
| `data-i18n-title` | 设置 title 属性 |
| `data-i18n-placeholder` | 设置 placeholder 属性 |
| `data-i18n-aria-label` | 设置 aria-label 属性 |

### 语言持久化

语言设置保存在：
1. Tauri 配置文件（`settings.language`）
2. localStorage（`language` 键）
