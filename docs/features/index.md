# 功能特性

ViewStage 提供以下核心功能：

- [摄像头展台](./camera.md) — 实时摄像头采集、拍照、旋转、镜像
- [PDF/文档展示](./pdf-document.md) — PDF 和 Word 文档导入展示
- [批注系统](./annotation.md) — 画笔批注、撤销/重做、清屏
- [画笔工具](./pen-tools.md) — 多色画笔、无级调节、钢笔笔锋效果
- [文档扫描](./doc-scan.md) — AI 边缘检测、文本检测、文档增强
- [文件管理](./file-management.md) — 图片列表、文件列表、源 ID 管理
