# 设置面板

设置面板通过侧边栏按钮或快捷键打开，包含以下页面：

## 应用设置

### 语言
- 支持简体中文、繁體中文、English
- 切换后需重启应用

### 分辨率
- 应用显示分辨率
- 可选预设分辨率或当前显示器最大分辨率
- 更改后需重启应用

### 设置管理
- **导出设置**: 导出配置文件备份
- **导入设置**: 从备份文件恢复设置
- **重置应用**: 清除所有设置并重启

## Canvas 调节

### 帧率模式
| 模式 | 说明 |
|------|------|
| 低帧率 | 固定 30 FPS，省电省资源 |
| 自适应 | 根据绘制负载动态调节（20-60 FPS） |
| 高帧率 | 固定 60 FPS，流畅绘制 |

### 钢笔效果
| 模式 | 说明 |
|------|------|
| 关闭 | 均匀线宽，无笔锋 |
| 限制 | 有限笔锋效果，适合教学 |
| 完整 | 完整笔锋效果，适合精细绘图 |

### 画笔颜色
- 支持修改 15 个预设颜色
- 内置取色器（HSV 选择）
- 支持十六进制颜色输入

## 信号源调节

### 摄像头设置
- **默认摄像头**: 选择默认摄像头设备
- **摄像头分辨率**: 设置采集分辨率
- **画面镜像**: 水平翻转画面
- **降噪帧数**: 多帧降噪（1/3/5/7 帧）
- **降噪强度**: 低/中/高
- **默认旋转角度**: 0°/90°/180°/270°

### PDF 设置
- **PDF 输出分辨率**: 2x-8x 可选
- **PDF 默认打开方式**: 注册为默认 PDF 打开程序
- **Word 默认打开方式**: 注册为默认 Word 打开程序

## 存储

### 缓存管理
- 查看当前缓存大小
- 手动清除缓存
- 自动清除缓存设置（关闭/每天/每周/每半月/每月）

### 日志
- 打开日志目录查看日志文件

## 文档扫描设置

### 基本设置
- 显示文档扫描按钮
- 扫描质量（标准/高质量/超高质量）
- 扫描模式（自动/手动）
- 增强模式（自动/文本增强/照片增强/无）

### 模型管理
- DBNet 文本检测模型（下载/删除）
- DexiNed 边界检测模型（导入/删除）
- UVDoc 文档矫正模型（下载/删除）

## 主题

- **深色主题**: 暗色调界面
- **简化主题**: 简洁明亮界面（默认）
