# 键盘快捷键

ViewStage 支持以下键盘快捷键：

## 模式切换

| 快捷键 | 功能 |
|--------|------|
| `V` | 移动模式 |
| `P` | 批注模式 |
| `E` | 橡皮擦模式 |

## 编辑操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Delete` | 清空批注 |

## 源切换

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 打开文件 |
| `Ctrl+I` | 导入图片 |

## 摄像头

| 快捷键 | 功能 |
|--------|------|
| `Space` | 拍照 |
| `R` | 旋转 |
| `M` | 镜像切换 |

## 界面

| 快捷键 | 功能 |
|--------|------|
| `Esc` | 退出全屏/关闭面板 |
| `F11` | 切换全屏 |
| `Ctrl+，` | 打开设置 |
